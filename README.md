# Creative Digital Art and Design

WSQ courseware for **TGS-2023037829**, delivered by Tertiary Infotech Academy Pte Ltd.

The programme uses two iPad drawing platforms:

- [Procreate](https://apps.apple.com/us/app/procreate/id425073498)
- [Sketchbook Studio](https://apps.apple.com/us/app/sketchbook-studio/id6782660312), a free Tertiary Infotech Academy learning tool

## Course package

- `courseware/` — trainer slides, learner slides PDF, Learner Guide and Lesson Plan
- `labs/` — 12 progressive, self-contained real-use-case labs; every Markdown guide has a matching PDF

Assessment papers are confidential trainer materials and are distributed through the authorised courseware Drive only. They are intentionally excluded from this public repository.

Course information: <https://www.tertiarycourses.com.sg/wsq-creative-digital-art-and-design.html>
